# Security

Please report vulnerabilities privately, through [GitHub's private reporting](https://github.com/AirKyzzZ/hermes-superagent/security/advisories/new), not in a public issue. If that form isn't available, open an issue that asks for a private contact and leave the details out.

What counts: anything that lets message or event text start or steer work, gets a worker past its tool guard, forges or replays a report, leaks a file through relay, makes the ledger close an item its source didn't close, or runs a command the operator didn't configure. The [threat model](DESIGN.md#threat-model) lists the controls and the known limits.

This is a one-person project, so expect a first answer within a few days.
